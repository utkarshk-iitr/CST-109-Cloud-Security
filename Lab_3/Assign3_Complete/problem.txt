Problem Statement

distributed and internet-facing nature. This assignment focuses on designing and 
implementing a secure cloud application architecture that integrates automated threat 
modeling, risk assessment, and mitigation mechanisms.

4. Data Storage Service 
5. Security Monitoring and Logging Module
